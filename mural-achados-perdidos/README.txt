MURAL DE ACHADOS E PERDIDOS

Como executar no VS Code:

1. Abra esta pasta no Visual Studio Code.

2. Abra o terminal.

3. Instale o Flask:
   pip install -r requirements.txt

4. Execute:
   python app.py

5. Abra no navegador:
   http://127.0.0.1:5000

O banco SQLite "achados_perdidos.db" será criado automaticamente na primeira execução.
